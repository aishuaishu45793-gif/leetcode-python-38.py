## 💡 Example Practice

Example problem:

### Find the Largest Number

```python
numbers = [10, 25, 8, 40, 30]

largest = numbers[0]

for number in numbers:
    if number > largest:
        largest = number

print("Largest:", largest)
```

### Output

```text
Largest: 40
```
